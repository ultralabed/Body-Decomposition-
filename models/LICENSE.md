# Model licence

The files in this folder (`skeleton.glb`, `muscles.glb`, `other.glb`) are derived
from **BodyParts3D** (release 3.0 / 20110915).

> BodyParts3D, © The Database Center for Life Science, licensed under
> CC Attribution-Share Alike 2.1 Japan.
> https://creativecommons.org/licenses/by-sa/2.1/jp/deed.en

Changes made: every part was converted from STL, simplified to a lower triangle
count, converted to metres with the y axis pointing up, and packed into
meshopt-compressed GLB files (see `tools/`).

Because the source is share-alike, these derived model files are distributed
under the same licence: **CC BY-SA 2.1 Japan**.
